## About me

I'm **Fady**, a Full-Stack .NET Developer based in Cairo, Egypt.

I enjoy building practical applications, working with databases, and turning business requirements into clear software solutions.

- 💻 My main stack is **C# and ASP.NET Core**.
- 🧩 I build backend applications with **REST APIs, Entity Framework Core, and SQL**.
- 🌐 I also work with **Next.js, React, and TypeScript**.
- 🏗️ I'm currently rebuilding **Stocka**, a multi-organization and multi-branch ERP system for small and medium retail businesses.
- 📚 I keep improving my skills through building, testing, and learning from real problems.

## What I'm working on

<div align="center">

### [Stocka](https://github.com/FadiFayezDev/Stocka)

**A multi-organization, multi-branch ERP system for retail businesses.**

</div>

Stocka aims to bring core retail operations into one system, from catalog and inventory to purchasing, sales, and accounting.

Current focus:
- Designing clear business workflows and domain models.
- Building a modular monolith with **.NET**.
- Keeping module boundaries clear through contracts.
- Using **PostgreSQL**, Entity Framework Core, and Dapper.
- Building a modern frontend with **Next.js**.

> Stocka is a work in progress and is being rebuilt. The current repository represents the ongoing version, not the older implementation.
